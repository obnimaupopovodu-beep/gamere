# Эхо Кондуита · Том 1 и 2

Кооперативная головоломка для двух игроков (Огонь и Вода). Ключ Gemini не нужен.

## Запуск

Нужен [Node.js](https://nodejs.org/) 20 или новее.

```bash
npm install
npm run dev
```

Откройте в браузере: http://localhost:3000

- Огонь: `W A S D`, действие `F`
- Вода: стрелки, действие `Enter`
- `Esc` — пауза, `R` — заново, `H` — справка
